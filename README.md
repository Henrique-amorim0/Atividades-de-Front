# Atividades de Front-end

Trabalhos organizados em pastas numeradas. Cada atividade mantém seu HTML, CSS, imagens e materiais de referência dentro da própria pasta.

## Atividades

| Atividade | Conteúdo | Pasta |
| --- | --- | --- |
| 1 | Bootstrap: carrossel, cards, accordion, modal e alertas | [atividade-01](./atividade-01/) |
| 2 | Tailwind CSS: Casinhas à Venda, com HTML e CSS separados | [atividade-02](./atividade-02/) |

## Como abrir a Atividade 1

1. Baixe o repositório em **Code > Download ZIP** e extraia os arquivos.
2. Abra `atividade-01/index.html` no navegador.
3. Mantenha a pasta `Imagem` junto do HTML para carregar as imagens do carrossel.

O Bootstrap é carregado por CDN e precisa de conexão com a internet.

Os arquivos `Orientações.txt`, `layout.png` e `modal.png` são os materiais de referência do exercício. A pasta `imagem.img` e o arquivo `style.css` foram mantidos da versão anterior.

## Como abrir a Atividade 2

Abra `atividade-02/index.html` no navegador, mantendo `style.css` e a pasta `imagem` junto do HTML. É necessário acesso à internet para carregar o Tailwind e as fontes. Os materiais de referência estão em `atividade-02/Atividade/`.

## Próximas atividades

Ao adicionar um novo trabalho, crie `atividade-03`, depois `atividade-04` e assim por diante. Atualize a tabela acima e mantenha os arquivos de cada trabalho dentro de sua pasta. Essas pastas serão criadas quando os respectivos trabalhos forem adicionados.
